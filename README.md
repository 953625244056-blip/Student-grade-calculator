# Student Marks Calculator

## Description
This is a simple C program to calculate a student's total marks, average, and grade based on the marks entered.

## Features
- Enter marks for subjects
- Calculate total marks
- Calculate average
- Display grade

## Language Used
- C

## How to Run
1. Compile the C program.
2. Run the program.
3. Enter the student's marks.
4. The total, average, and grade will be displayed.
